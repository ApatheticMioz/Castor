Engine Architecture

Engineered in Rust for Zero-Trust Autonomy

Unlike brittle Python agent wrappers, Castor is an in-process microkernel built to protect codebases while maximizing local throughput.

5-Layer Containment Sandbox

137 attack vectors tested. Lexical normalizers, canonical root guards, and symlink realpath resolvers guarantee the model never reads or mutates files outside your active project root.

In-Memory AST Syntax Gate

Every code replacement is parsed via tree-sitter in memory before disk commit. Any syntax error triggers automatic rollback, completely eliminating repository breakage.

KV-Cache Slot Semaphore

Dynamic token-budget admission tracks committed context against aggregate VRAM capacity. Tasks yield cooperatively, preventing GPU out-of-memory crashes while sustaining 4 concurrent streams.
